## ̇ スターバック機構

このレポは、そのスターガザーを監視し、自動的に各新しいスターガザーの最高のパブリックレポを星空に見ているアクション(`star-back.yml`)を実行します。 星 → 星を戻す. 自動化された共同体。

## ✓ スターベイトが機能する理由

- 星はGitHubのランキング信号です。すべての星は「探索」フィードでレポを高く押します
- gimmickは自己文書化です:README *is*ピッチ
- 成長化合物:各星は、そのユーザーのフォロワーにレポを公開します
